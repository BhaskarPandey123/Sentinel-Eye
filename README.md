## Problem Reason

  Generative AI has made digital content increasingly realistic, making it difficult to distinguish authentic human-created media from manipulated or AI-generated content. Nowadays, media can be generated with just a few specialised and proper prompts, and we can get an image that looks totally okay and can be used anywhere. I am bringing this project to protect the authenticity of original human work! I **Bhashkar Pandey** am bringing this project with 8 layers.

## The Challenge
 
   To build a reliable way to verify digital media using digital forensics, AI/ML, metadata and content verification techniques, while providing users with an understandable confidence score and supporting evidence.

## The Solution

  The solution to this problem is our Sentinel eye, which goes through low-level details of images and videos and checks for each possible imbalance and lack of information in the image data and gives a confidence score to help us understand if the content is authentic, with a reason.

## Layers

Sentinel Eye uses an 8-layer investigation pipeline:

| Layer | Analysis |
|---|---|
| **01 — Metadata Analysis** | Examines available metadata and media provenance indicators. |
| **02 — Reverse Search** | Helps determine whether the media has appeared online previously. |
| **03 — Digital Forensics** | Examines digital artifacts and inconsistencies within the media. |
| **04 — Audio Analysis** | Evaluates audio characteristics for potential manipulation or synthetic content. |
| **05 — Video Analysis** | Examines video frames and temporal consistency for irregularities. |
| **06 — AI/ML Detection** | Uses detection techniques to identify patterns associated with synthetic or manipulated media. |
| **07 — Cross-Source Verification** | Compares available contextual information across external sources. |
| **08 — Decision Intelligence Dashboard** | Combines the available evidence into an understandable confidence assessment with supporting findings. |

> Each layer provides an independent piece of evidence. Sentinel Eye combines these findings rather than relying on a single indicator to determine authenticity.
