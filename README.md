# Sentinel-Eye
This project is developed by Bhashkar Pandey and all rights are reserved by Bhashkar Pandey and his team.

## Problem Reason

  Generative AI has made digital content increasingly realistic, making it difficult to distinguish authentic human-created media from manipulated or AI-generated content. Nowadays, media can be generated with just a few specialised and proper prompts, and we can get an image that looks totally okay and can be used anywhere. I am bringing this project to protect the authenticity of original human work! I **Bhashkar Pandey** am bringing this project with 8 layers.

## The Challenge
 
   To build a reliable way to verify digital media using digital forensics, AI/ML, metadata and content verification techniques, while providing users with an understandable confidence score and supporting evidence.

## The Solution

  The solution to this problem is our Sentinel eye, which goes through low-level details of images and videos and checks for each possible imbalance and lack of information in the image data and gives a confidence score to help us understand if the content is authentic, with a reason.
