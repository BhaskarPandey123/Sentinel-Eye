Upload an image or short video. Sentinel Vision runs it through a set of independent forensic layers — metadata, error-level analysis, noise-consistency analysis, and (for video) frame-consistency checks — all computed live in your browser, then combines the findings into an explainable confidence score. This build is a working prototype of the pipeline; two layers (deep audio/video AI detection and automated cross-platform crawling) are stubbed with manual tools pending a server-side backend — see the notes at the bottom.

Notes on this build. Metadata, error-level analysis, and noise-consistency are genuine computations run on the actual pixel/byte data of your file — not simulated. Reverse-image search and cross-source checks require server-side crawling or paid APIs (Google, Bing, TinEye) which this static prototype doesn't have credentials for, so those layers hand you direct, working links to run the check yourself. AI-generated-media detection here is a texture/noise-based heuristic, not a trained deepfake classifier — a production version would plug in a model such as an EXIF-CNN or DCT-artifact classifier here. Audio voice-clone detection is not implemented in this build. Nothing you upload leaves your device.
